# An AI-Driven 8-Bit Web Game For Personalized College Program Matching and Career Exploration
This project is a unique educational technology platform that uses the nostalgic aesthetic of an 8-bit web game to guide students through the complex process of college program matching and career exploration. By integrating a modern AI recommendation engine with a fun, gamified user experience, we aim to make informed decision-making accessible, engaging, and personal.

### Key Features
- __8-Bit Gamified Experience__: A pixel-art interface and narrative structure (Ex. Creating your avatar, playing different types of quizzes) to drive engagement.
- __Personalized AI Matching__: The heart of the game is its intelligent recommendation system, powered by the __Gemini API__, this system analyzes the player's performance and choices across a series of engaging, in-game 8-bit quizzes. Generates a ranked list of the best-fit programs based on _Quiz Score_ and _Skills and Personalization_, complete with a natural language explanation (justification).
- __Dynamic Program Recommendations__: Provides highly relevant and accurate, ranked suggestions for college courses or career fields with justification for the match.
- __Cross-Platform Web Deployment__: Accessible instantly via any web browser (desktop and mobile-friendly).
- __Progress Persistence__: User progress, profile data, and AI recommendation and suggestion are saved to track growth and refine recommendations over time.

### Prerequisites
- Device (Personal Computer, Laptop, Tablet, or any Mobile Devices)
- Web Browser (Chrome, Firefox, or Edge)

### Tech-Stack
- Frontend: HTML5, CSS3, JavaScript (ES6+)
- Backend: Node.js (Express.js)
- Game Engine: Phaser.js
- AI Engine: Google Gemini API
- Database: Firebase Realtime Database
- Deployment: GitHub Pages (Frontend), Render (Backend)
